# Redmine.org Automated Test Suite

## Description
This project contains an automated end-to-end (E2E) test suite for the [Redmine.org](https://www.redmine.org/) website. The tests are developed using [Playwright](https://playwright.dev/) and TypeScript, implementing the Page Object Model (POM) design pattern to ensure code maintainability, readability, and reusability. Test execution reporting is handled by **Allure Report**.

Continuous Integration (CI) and deployment of the test reports are configured via **GitHub Actions** and **GitHub Pages**.

## Project Structure

Based on standard Playwright architecture, the repository is structured as follows:

```bash
redmine-playwright-test/
├── .github/
│   └── workflows/
│       └── cypress.yml     # CI/CD pipeline configuration for GitHub Actions
├── allure-results/         # Raw JSON/XML data generated by Allure (auto-generated)
├── downloads/              # Directory for files downloaded during test execution
├── node_modules/           # Project dependencies (ignored in git)
├── pages/                  # Page Object Model (POM) classes
│   ├── HomePage.ts         # Locators and methods for the Main page
│   └── LoginPage.ts        # Locators and methods for the Login form
├── playwright-report/      # Default Playwright HTML report (auto-generated)
├── test-results/           # Playwright traces, screenshots, and test artifacts
├── tests/                  # Test specification files
│   └── redmine.spec.ts     # Main test suite covering 5 required test cases
├── .gitignore              # Files and directories ignored by Git
├── package-lock.json       # Exact versions of installed npm dependencies
├── package.json            # Project metadata, dependencies, and npm scripts
├── playwright.config.ts    # Global Playwright configuration file (browsers, reporters, etc.)
└── README.md               # Project documentation
```

*(Note: Directories like `allure-results`, `downloads`, `playwright-report`, `node_modules`, and `test-results` are excluded from version control via `.gitignore`).*

## Environment Variables

Create a `.env` file in the root directory based on the `.env.example` structure to store sensitive credentials securely:

```bash
REDMINE_USERNAME=your_username
REDMINE_PASSWORD=your_password
```
*(The `.env` file is added to `.gitignore` to prevent secret leaks).*

## Prerequisites

Before running the tests locally, ensure you have the following installed:

* Node.js (version 16 or higher)
* Git

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/ErnestSosnovskyi/Playwright.git
cd Playwright
```

2. Install project dependencies:

```bash
npm install
```

3. Install Playwright browsers:

```bash
npx playwright install --with-deps
```

## Running the Tests via NPM Scripts

The `package.json` file includes convenient scripts for running test suite across all configured browsers (Chromium, Firefox, WebKit) and generating reports:

* **Run all tests in headless mode:**

```bash
npm run test
```

* **Run tests in UI mode (interactive mode):**

```bash
npm run test:ui
```

## Viewing Test Reports

This project uses Allure to generate visually appealing and detailed test reports.

1. **Generate and open the Allure report:**
After the tests are completed, run the following command to serve the report locally:

```bash
npm run report
```
*(This will automatically open the generated HTML report in your default web browser).*

2. **Default Playwright Report:**
You can also view the built-in Playwright HTML report:

```bash
npm run show-report
```

## CI/CD Pipeline (GitHub Actions)
This project is equipped with a GitHub Actions workflow that runs automatically on every push to the `main` branch.

* It installs dependencies.
* Runs the Playwright test suite.
* Generates an Allure report.
* Deploys the Allure report to GitHub Pages.
